## Overview

This repository contains my personal developer portfolio — a digital space where I present my technical skills, selected projects, learning journey, and interests in modern web development and cybersecurity.

The portfolio is designed with a strong focus on **clean visual presentation, responsive layouts, interactive experiences, smooth animations, and professional project storytelling**.

Rather than being just a static profile page, the website is intended to represent how I approach technology: **building, experimenting, learning, and continuously improving.**
